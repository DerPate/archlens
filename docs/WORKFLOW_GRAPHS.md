# Workflow Graphs

**Regenerated 2026-08-16** against the current tree. Every code block below is verbatim tool
output — no figure in this file was typed by hand. To reproduce it, build the jar and replay the
calls named under each heading against `index_workspace { "paths": ["<repo root>"] }`.

ArchLens indexing itself is the most convenient end-to-end test of the tools: the server is a
plain Java application with a single `main` entrypoint, so the results show what the extractors
recover from ordinary code with no framework annotations to lean on.
