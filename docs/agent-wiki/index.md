# ArchLens Architecture Knowledge

This bundle documents ArchLens's own architecture — the tool that produces it. It was
generated by indexing this repository with ArchLens's own MCP tools
(`index_workspace`, `find_components`, `find_entrypoints`) and reading its checked-in
`docs/TOOLS.md` and `docs/GENERATED_ARCHITECTURE.md`, so structural claims (packages,
component counts, class names, tool arguments) are source-derived rather than invented.
Every concept below carries `verified: { by: human:dominik }` and `status: stable` —
reviewed on 2026-09-17.
